Program de gestiune a unui depozit de brățări fitness, scris în Java.
Tehnologii

Limbaj: Java
IDE: IntelliJ IDEA
JDK: 21

Funcționalități

Citire vector de brățări fitness de la tastatură
Afișarea tuturor produselor din depozit
Căutare după Brand și Preț
Filtrare după Compatibilitate (iOS / Android / Universal)
Ștergere după Brand și Preț
Sortare după Durata Bateriei (bubble sort, crescător)
Generare matrice cu durata bateriei pe diagonala principală
